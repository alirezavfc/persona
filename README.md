# Persona

Persona is a minimal text-based social network focused on user interaction, privacy, and a simple social experience.

Users are represented by numbered identities such as `Persona 001`, rather than real names.

## Planned Features

- User registration and login
- Public user profiles
- Numbered Persona identities
- Follow and unfollow
- Following-only feed
- Text and image posts
- Comments
- User and post search
- Private messaging
- Privacy-focused messaging architecture

## Status

Early development.

The project is currently in the research, requirements, and architecture phase.

## Goals

The main goal of Persona is to practice software engineering and full-stack web development through building a real-world application from requirements to deployment.
