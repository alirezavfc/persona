# Persona — MVP Scope

## 1. Product Overview

Persona is a social networking application where users can discover people, view profiles, browse posts, and search for users and content.

The initial version focuses on building the frontend interface with Next.js, TypeScript, Tailwind CSS, and mock data.

## 2. MVP Goals

- Establish the main page structure and navigation.
- Build reusable UI components using Next.js.
- Practice rendering and managing mock data.
- Create a foundation for future backend integration.

## 3. Target Users

People who want to explore a social network, discover users, and browse posts.

## 4. Features in Scope

- **Feed:** Display a list of posts using mock data.
- **User Profiles:** Display a user's basic information and posts.
- **My Profile:** Display the current user's profile using mock data.
- **Login and Sign-up:** Build the authentication page interfaces without implementing real authentication.
- **Search:** Search mock users and posts by a text query.
- **Navigation:** Allow users to move between the main pages.

## 5. Out of Scope

The following features will be implemented in later development phases:

- Backend and database integration.
- Real authentication and account recovery.
- Creating, editing, liking, replying to, or reposting posts.
- Following and unfollowing users.
- Notifications and direct messaging.
- End-to-end encryption.
- Production deployment and production-level security.

## 6. Technical Scope

- Next.js
- TypeScript
- Tailwind CSS
- Mock data for users and posts

## 7. Success Criteria

The MVP is complete when:

- All planned pages are implemented.
- Users can navigate between the main pages.
- The feed and profile pages display mock data correctly.
- Search returns matching mock users and posts.
- The interface works on mobile and desktop screen sizes.
